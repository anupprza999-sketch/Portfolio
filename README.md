# 3D Artist Portfolio - Anup Prajapati

A professional, immersive 3D artist portfolio website featuring cinematic scroll-driven experiences, real-time 3D rendering, and interactive animations.

## Tech Stack

### Frontend
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Three.js + React Three Fiber + Drei
- GSAP + ScrollTrigger

### Backend
- Node.js + Express + TypeScript
- Zod (runtime validation)
- REST API

## Getting Started

### Prerequisites
- Node.js v20+ (LTS recommended)
- npm v10+
- Git

### Development

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

**Backend:**
```bash
cd backend
npm install
npm run dev
```
